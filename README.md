# Python for Data Science

A collection of Python-based data science exercises and exploratory data analysis (EDA) projects completed as part of my learning journey.

## Projects

| Project | Description | Tools & Libraries |
|---|---|---|
| [Smartphone Usage and Addiction EDA](Smartphone_EDA.ipynb) | Exploratory analysis of 7,500 synthetic records to investigate smartphone usage patterns and their association with addiction. | Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy |
| [Telecom Customer Churn EDA](Telcom_EDA.ipynb) | Exploratory analysis of 7,043 customer records to investigate churn patterns across demographics, services, contracts, and billing characteristics. | Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy |
| [Titanic Survival EDA](Titanic_EDA.ipynb) | Exploratory analysis of 891 Titanic passenger records to investigate survival patterns across demographics, passenger class, fare, and family characteristics. | Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy |
| [Credit Risk Analysis](Credit_EDA.ipynb) | Explores applicant demographics, financial characteristics, missing values, class imbalance, and repayment patterns. | Pandas, NumPy, Matplotlib, Seaborn |

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
